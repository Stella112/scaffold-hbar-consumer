# Contract interfaces (frozen at end of M0)

Changing anything here requires a DECISIONS.md entry and a handoff note. Source of truth:
`packages/foundry/contracts/`; TypeScript mirror: `packages/sdk/src/` (ABIs generated by `yarn sdk:abis`).

## EIP-712 domain

`name = "ConsumerAccount"`, `version = "1"`, `chainId = 296` (testnet), `verifyingContract = <account>`.

```
Call(address target,uint256 value,bytes data)
OwnerIntent(Call[] calls,uint256 nonce,uint64 validUntil)
SessionAction(bytes32 actionId,bytes actionData,uint256 nonce,uint64 validUntil)
TransferAuthorization(address from,address asset,address to,uint256 amount,uint256 nonce,uint64 validUntil)
```

## ConsumerAccount entrypoints

| Function | Who authorizes | Notes |
| --- | --- | --- |
| `executeOwnerIntent(OwnerIntent, bytes sig)` | owner signature | Raw calls. Session signer → `RawCallForbidden`. Target `0x167` → `HtsCallMustBeTyped`. |
| `executeSessionAction(SessionAction, bytes sig)` | owner (no caps) or live session (policy) | Typed actions only. |
| `executeTransfer(from, asset, to, amount, authorization)` | owner or session with `X402_PAYMENT` | x402 `ITransferExecutor`, selector `0xea8f19fd`. `authorization = abi.encode(uint256 nonce, uint64 validUntil, bytes sig)`. |
| `grantSession`, `revokeSession`, `setOwner`, `setOracle`, `setSwapRouter`, `associateToken`, `setGuardians`, `cancelRecovery` | `onlySelf` (owner intent self-call) | |
| `proposeRecovery(newOwner)`, `approveRecovery()` | guardian (msg.sender) | |
| `executeRecovery()` | anyone after threshold + timelock | Bumps `ownerEpoch` (revokes sessions). |

## Typed actions (`Actions.sol` ↔ `sdk/src/actions.ts`)

| Name | ID preimage | `actionData` |
| --- | --- | --- |
| payment | `consumer.action.payment.v1` | `abi.encode(address asset, address to, uint256 amount)`; asset 0 = HBAR (tinybars) |
| airdrop | `consumer.action.airdrop.v1` | same; HTS token only; HIP-904 `airdropTokens` |
| swap-to-pay | `consumer.action.swap-to-pay.v1` | `abi.encode(SwapToPay{router,tokenIn,amountInMaximum,tokenOut,amountOut,to,deadline,path})` |
| x402-payment | `consumer.action.x402-payment.v1` | permission for `executeTransfer` only |

Reserved (session → revert): `consumer.admin.{set-owner,grant-session,revoke-session,set-guardians,recovery,set-oracle}.v1` → `PrivilegeEscalation`; `consumer.action.vault-{withdraw,redeem}.v1` → `WithdrawForbidden`.

## Session policy evaluation order

1 session exists (else `SignatureInvalid`) · 2 not expired (`SessionExpired`) · 3 raw call (`RawCallForbidden`, owner-intent path) · intent expiry/replay (`IntentExpired`, `IntentReplayed`) · 4 privileged (`PrivilegeEscalation`) · 5 withdrawal (`WithdrawForbidden`) · 6 action allowed (`ActionNotAllowed`) · 7 target (`TargetNotAllowed`, swap router) · 8 recipient (`RecipientNotAllowed`) · 9 price (`PriceUnavailable`) · 10 per-call cap · 11 daily cap.

## IPriceOracle

`quoteUsd6(address asset, uint256 amount) view returns (bool ok, uint256 usd6)` — must return `ok=false` for unsupported, stale or invalid prices.
