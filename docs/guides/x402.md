# x402

## Paid resource

`GET /api/x402/premium` (0.05 HBAR) returns **402** with a `PAYMENT-REQUIRED` header (x402 v2, scheme `exact`,
network `hedera:testnet`, `assetTransferMethod: transferExecutor`, `executors: [...]`). A retry with
`PAYMENT-SIGNATURE` is verified and settled before the live HBAR/USD data is returned with `PAYMENT-RESPONSE`.

## transferExecutor

`@x402/hedera@2.28.0` implements only `cryptoTransfer`. This template implements the `transferExecutor` method of
`scheme_exact_hedera.md` on `@x402/core`:

- **Client** `TransferExecutorClient` (SDK): signs a `TransferAuthorization(from, asset, to, amount, nonce,
  validUntil)` for the account; `authorization = abi.encode(nonce, validUntil, signature)`.
- **Facilitator** `TransferExecutorFacilitator` (relayer), `/api/x402/facilitator/{supported,verify,settle}`:
  shape checks, executor admission (factory accounts only), address resolution, calldata built only from the
  requirements, simulation with a gas cap, `ContractExecuteTransaction` settlement, and conformance of the
  parent + child transfer records (payTo credited exactly; only payer and fee payer debited).
- **Account** `executeTransfer`: verifies the signer (owner, or session with `x402-payment`), charges the
  session's caps, transfers.

Replays fail on the nonce; changing the amount breaks the signature (testnet flow 6). Agents pay through the MCP
tool `purchase_x402` or the Agent page.
